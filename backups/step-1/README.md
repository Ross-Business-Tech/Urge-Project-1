**What it is:** a Grant Report Builder that turns a month of messy Brightpath data (Google Forms, attendance spreadsheet, volunteer emails, donor database) into a funder report ready for review.
**How to open it:** double-click `index.html` in this folder; it works offline in any modern browser, with no install or login.
**What is simulated:** all data is invented, and the "AI" that pulls out hours, dates and stories is rule-based ("Prototype AI (simulated)", in `ai.js`). A real AI model could replace the `askAI()` function later.
